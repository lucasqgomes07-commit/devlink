# DevLinks

Página de links (estilo "link na bio") feita como projeto final do curso Discover da Rocketseat.

## Tecnologias
- HTML5 semântico
- CSS3 (variáveis, flexbox, grid, responsivo, respeita `prefers-reduced-motion`)
- JavaScript puro (botão de copiar link com feedback)

## Como rodar
Abra o `index.html` no navegador. Não precisa instalar nada.

## Como personalizar
Edite em `index.html`: nome, bio e os `href` de cada link (GitHub, LinkedIn, WhatsApp e e-mail) ou adicione novos `<li>`.

## Publicar online (GitHub Pages)
Settings > Pages > Branch `main` / pasta `/ (root)`.
